## 🧑‍💻 How to Run Locally

1. Clone the repo:

    ```bash
    git clone https://github.com/Himanshu-Kumar-2301/fcc-js-regex-sandbox.git
    ```

2. Navigate into the folder

    ```bash
    cd fcc-js-regex-sandbox
    ```

3. Open ```index.html``` in your browser.
